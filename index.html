区块一 ｜ 资金流入统计（一级分类 · 行业指数）

PART 1 ｜ 一级分类资金流入统计（近2周 / 近1月 / 近3月 / 近半年 / 近1年 流入与流入比率）

流入 = 区间内各基金资金净流入求和（亿元）；流入比率 = 区间净流入 ÷ 区间总规模均值(剔除0值)，参考原增速公式。分类顺序固定为：宽基指数 / SMARTBETA / 行业指数 / 另类投资 / 海外指数 / 信用债 / 利率债 / 可转债 / 类货币；列先全部流入、后全部比率，默认按固定顺序，列可排序。

PART 2 ｜ 行业指数资金流入统计（按二级分类｜近2周 / 近1月 / 近3月 / 近半年 / 近1年 流入与流入比率）

筛选一级分类为「行业指数」，按二级分类合并统计；列先全部流入、后全部比率；默认按近2周流入从高到低排序，列可排序。

PART 8 ｜ 折溢价率分位统计（一级 / 二级 / 三级 联动筛选 ｜ 前5列与表头锁定 ｜ 底部滑块横向滚动）

PART 9 ｜ 基于行业概念的ETF筛选

分别通过下拉勾选「行业分类」与 7 个概念分组（消费 / 医药 / 科技 / 制造 / 周期 / 金地 / 香港，可同时多选，支持搜索与全选/清空）。勾选完成后点击右侧确定才会刷新列表；列表默认按汇总仓位（所选分类权重之和，单位 %）从大到小排序，点击任意列标题可切换升序/降序；列依次为：排名、ETF代码、ETF简称、一级/二级/三级分类、最新规模、得分、汇总仓位，随后为每个被勾选分类的权重列；点击确定后仅保留汇总仓位 > 5% 的 ETF（最多 500 名），列较多时可横向滚动查看。
